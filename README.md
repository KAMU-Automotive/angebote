# KAMU Angebote

Web-App (PWA) zum Erstellen von Angebotsbildern für **KAMU KFZ Werkstatt** und **KAMU-PARTS**
im Format 9:16 (WhatsApp-Status/Story) und 1:1 (Facebook/Google).

Alle Fotos und der Verlauf bleiben ausschließlich auf dem Gerät. Es gibt keinen Server und keine Datenbank.

## Verwendete Fremd-Software
- Hintergrund-Erkennung: [@imgly/background-removal](https://github.com/imgly/background-removal-js) 1.4.5, AGPL-3.0 (Modell- und WASM-Dateien im Ordner `bg/`)
- Schrift: [Inter Display](https://rsms.me/inter/), SIL Open Font License 1.1

Der Quellcode dieser App ist in diesem Repository vollständig einsehbar (AGPL-3.0).
